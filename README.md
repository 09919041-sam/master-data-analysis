
# ToysGroup – Progetto finale Python per Data Analysis

## Descrizione

Analisi dei dati commerciali di ToysGroup realizzata
come progetto finale del corso di Python per Data Analysis.

## Obiettivi

- Importazione ed esplorazione dei dataset
- Pulizia e trattamento dei valori mancanti
- Aggregazione e analisi delle vendite
- Analisi delle serie temporali
- Visualizzazione dei dati
- Regressione lineare
- Analisi del churn, subordinata alla disponibilità del target
- Segmentazione dei rivenditori con KMeans

## Tecnologie utilizzate

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## File del progetto

- `ToysGroup_Analisi_Finale.ipynb`
- `products.csv`
- `regions.xlsx`
- `sales.json`
- `resellers.csv`

## Esecuzione

1. Installare le librerie necessarie.
2. Aprire il notebook in VS Code o Jupyter.
3. Selezionare un kernel Python con le librerie installate.
4. Eseguire tutte le celle dall'inizio.
